# 个人作品集网站

米白涂鸦速写本风格的可交互作品集，面向游戏 / 互联网公司的动效设计与品宣视频岗位。

## 怎么打开（两种方式都可以）

1. **直接双击 `index.html`** —— 无需任何环境，浏览器里直接用
2. 本地服务器方式：用任意静态服务器指向本文件夹（如 `node serve.mjs`），访问 http://localhost:4173

## 改内容（不需要编程）

所有文字和作品都集中在 **`content/data.js`** 一个文件里，用记事本就能改：

- `site` 部分：你的名字、职位、简介、技能条数值、软件、经历（剪辑时间线）、联系方式、简历链接
- `works` 部分：视频作品，电影票根样式卡片，每个作品一段 `{ ... }`
  - `cat` 分类只能是：动效 / 特效 / 动画 / 其他
  - `poster` 封面图：把图片放进 `assets/`，这里填 `assets/文件名.jpg`
  - `video` 视频：把 mp4（建议 1920x1080）放进 `assets/`，这里填 `assets/文件名.mp4`；留空 `""` 则显示封面占位
  - `likes` 初始喜欢数（访客点的喜欢会在此基础上 +1）
- `postcards` 部分：明信片堆（图片作品），每堆一个 `{ ... }`，`cards` 里每张图配一句说明
  - 新增一堆：复制一整段改内容；图片同样放 `assets/`

访客数据和作品数据完全隔离：每个作品的喜欢数、评论列表各自独立存储（按作品 id 存在浏览器 localStorage）。

改完保存，刷新浏览器即生效。

## 页面里藏着的玩法

- 点击任意位置：蜡笔火花
- 按键输入 ↑↑↓↓←→←→BA：彩蛋（再输一次恢复）
- 页脚「颗粒」开关：胶片噪点开关
- 「音效」开关：界面音效（合成器实时生成，无音频文件）

## 技术说明（供参考，不需要操作）

- 纯静态站点：HTML + CSS + 原生 JS，无构建步骤
- 动效库已下载到 `assets/vendor/`（GSAP、ScrollTrigger、Lenis、Three.js），全部本地加载
- 字体在 `assets/fonts/`（站酷快乐体、Gaegu，均免费可商用）
- 双击可用是因为内容数据写在了 data.js 里而非异步加载，请勿把 data.js 改成 .json

## 首屏手账本（PDF 作品集）

首页的手账本会读取 `assets/portfolio.pdf`：把你的作品集 PDF 文件改名为 `portfolio.pdf` 放进 `assets/` 文件夹，刷新即可左右拖动翻页（带翻页动画）。没有这个文件时显示占位提示。
## 结构说明

- 所有样式已内联在 `index.html` 的 `<style>` 标签里（避免缓存问题，双击直接用）。`css/` 文件夹是副本，不用管。
- 首页笔记本：封面 → 点击/左滑翻开 → AE动画 / 角色IP / 毕业设计（整册 PDF）/ 涂鸦 四个页签
