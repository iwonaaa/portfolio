============================================================
作品集网站 · 上线与后台使用说明
============================================================

这份文档面向完全不会写代码的你。跟着点就行，全程免费。

需要两个免费账号：GitHub（存文件）和 Netlify（托管网站）。


------------------------------------------------------------
一、把网站弄上线（一次性，约 15 分钟）
------------------------------------------------------------

【第 1 步】注册 GitHub
  1. 打开 https://github.com → 点 Sign up → 用邮箱注册（免费）
  2. 验证邮箱，完成注册

【第 2 步】把网站文件传上 GitHub
  1. 登录后，右上角 + 号 → New repository
  2. 名字填 portfolio（或任意英文名），选 Public，其他都不动，
     点 Create repository
  3. 创建后点页面上的 "uploading an existing file" 链接
  4. 在电脑上打开文件夹 outputs/portfolio，全选里面所有文件和
     文件夹（index.html、admin、assets、content、css、js、
     netlify.toml），直接拖进网页的拖放区
  5. 等上传完，点页面底部绿色 Commit changes

  注意：拖进去的第一层就应该是 index.html，不要再多套一层文件夹。

【第 3 步】用 Netlify 发布
  1. 打开 https://www.netlify.com → Sign up → 选 GitHub 账号
     直接登录（免注册）
  2. 登录后直接打开这个地址进入导入流程：
     https://app.netlify.com/start
     （或在控制台首页找 Add new site → Import an existing project）
  3. 点 GitHub → 授权 → 找到你的 portfolio 仓库
  4. 构建设置全部留默认（Netlify 会自己读 netlify.toml），点 Deploy
  5. 等 1~2 分钟，顶部出现你的网址，形如 https://随机词.netlify.app
  6. 网址里的随机名不好记的话：Site configuration →
     Change site name → 改成比如 xu-portfolio.netlify.app

  >>> 这个网址就是发给 HR 的链接，任何人点开都能看，不需要登录 <<<

【第 4 步】把网站设为公开（新网站默认是私密的，必须做这步）
  1. 项目主页，项目名下面那排按钮里点 Make public
  2. 这样 HR 打开链接就不用登录了
  （项目名旁边的 Private 锁如果不管它，别人打开会要求登录）

【第 5 步】开通后台登录权限（上传/改内容需要密码）
  1. Netlify 项目页 → 左侧 Access & security → Identity →
     点 Enable Identity
  2. 同一页找 Services → Git Gateway → 点 Enable Git Gateway
  3. 回到 Identity 页 → Invite users → 输入你自己的邮箱 →
     去邮箱点邀请链接设密码

【第 6 步】进后台
  打开 https://你的网址.netlify.app/admin → 用刚设的邮箱+密码登录。
  这就是你的后台。


------------------------------------------------------------
二、后台都能改什么
------------------------------------------------------------

详细的改文字 / 传视频 / 传图片操作，看同目录下的
《后台修改内容教程.md》。

后台左边有三栏内容，改完点右上角 Save（保存），等 1~2 分钟
网站自动更新。

【站点文字与设置】
  - 名字、职业一句话、签名语、所在地状态
  - 手账页签介绍（首页 3D 手账里 AE动画/角色IP/毕业设计 三页的文字）
  - 关于我（角色面板的两段简介）
  - 技能条（软件名 + 等级 0-100）
  - 软件徽章
  - 经历时间线（每条：时间段、标题、公司、描述）
  - 联系方式（邮箱、电话、微信、简历 PDF 链接、B站主页）
  - 背景音乐：填一个 mp3 链接（先在后台左侧 Media 素材库里上传
    mp3，再把地址复制进来）。填了之后：访客打开网页第一次点击时
    音乐自动淡入播放；右上角"音乐"按钮可手动关；打开作品放映厅时
    音乐自动淡出，关掉弹窗自动淡入
  - 音效默认开启：勾选后访客打开网页默认有翻页/点击音效
    （不勾选则默认静音，访客可以自己开）

【作品（视频卡）】
  每条作品是一张"电影票根"：
  - 标题 / 英文名 / 分类（动效/特效/动画/其他）/ 年份 / 时长
  - 我的职责、使用软件、介绍文字
  - 封面图：票根上黑色的预览区，后台直接上传图片
  - 视频文件：上传 mp4 后，点票根弹出的放映厅就能播放；
    不上传则显示封面图 + 模拟播放预览
  - 初始点赞数（只是个起始数字，真实点赞存在访客自己浏览器里）
  - 新增作品：点 New 作品；删除：条目右上角菜单

【明信片堆（图片作品）】
  - 每一堆：标题、英文名、若干卡片（图片 + 图注）
  - 用于展示海报、手绘、设定集这类图片作品

【素材库（Media）】
  后台左侧 Media → 上传图片/视频/简历 PDF。上传后复制它给的地址，
  填到对应字段里。
  - 作品封面图、视频、明信片图片都在这里传
  - 简历 PDF 传完后，把地址填到「联系方式 → 简历 PDF 链接」


------------------------------------------------------------
三、不能在后台改的东西（找文件换）
------------------------------------------------------------

  想换什么                                    换哪个文件
  ------------------------------------------------------------
  整册作品集 PDF（手账毕业设计页翻的那个）      替换 assets/portfolio.pdf
  背景音乐文件                                 替换 assets/bgm.mp3
  联系区背景插画                               替换 assets/contact-bg.png
  手绘字体 / 颜色风格                          css/style.css（建议找我改）

  换文件后要同步到公网：GitHub 仓库 → Add file → Upload files →
  把新文件拖进去覆盖 → Commit changes → 等 1~2 分钟生效。


------------------------------------------------------------
四、常见问题
------------------------------------------------------------

问：改了后台内容，网页没变？
答：后台点了 Save 之后，Netlify 要 1~2 分钟重新构建。
    刷新网页时按 Ctrl+F5 强制刷新。

问：公网网址会因为我改内容而变吗？
答：不会。后台改内容自动上线，网址永远不变。
    只有换文件（见上面第三节）才需要去 GitHub 重新传。

问：点赞和评论数据会同步吗？
答：会。全站共享——任何人点赞或评论，所有访客都能看到
    （存在 Netlify Blobs 数据库里，免费额度内够用）。
    唯一例外：在本机 localhost 预览时数据存在本机浏览器里。

问：视频太大传不上？
答：建议先用剪映/HandBrake 压到 20MB 以内
    （1080p、码率 4Mbps 左右足够清晰）。

问：后台网址 /admin 打不开或一直转圈？
答：确认 Netlify 的 Identity 和 Git Gateway 都已开启
    （第一节第 5 步），并且你是被邀请的用户。

问：后台登录提示 "Email not confirmed"（邮箱未验证）？
答：邀请/重置邮件里的链接需要网站上的身份组件来确认。
    把最新的 index.html 和 admin/index.html 传上 GitHub 后：
    Identity → Users → 点你的账号 → Send reset password email →
    打开邮件里的链接 → 网站会弹出"设置密码"窗口 → 设好密码即
    完成验证，之后 /admin 就能登录了。

问：手机上能正常看吗？
答：能。网页已适配手机：票根自动单列、书本完整显示、
    翻页涂鸦在触屏上都能用。

问：想自己先在本机预览？
答：双击 index.html 打不开内容（浏览器安全限制）。
    在 hr 文件夹里运行：
      node work/serve.mjs outputs\portfolio 4173
    然后访问 http://localhost:4173/
